# ARKsic Documentation Index

This is the entry point for ARKsic's documentation. Each subfolder has its
own `README.md` that acts as an index for that section — start there rather
than browsing files directly.

| Section | Purpose |
|---|---|
| [`proposal/`](proposal/README.md) | What ARKsic is, who it's for, and what it will (and won't) do |
| [`foundation/`](foundation/README.md) | The architectural and technical decisions the project is built on |
| [`implementation/`](implementation/README.md) | How those decisions are realized in code, module by module |

## Reading order

1. **Proposal** — read first for context on scope and goals.
2. **Foundation** — read to understand *why* the project is structured the way it is.
3. **Implementation** — read when you need to know *how* a specific piece works, or before contributing code.

## Conventions

- Every `README.md` under `docs/` is an index page, not a dumping ground for
  prose: it should summarize and link out to focused documents rather than
  grow without bound.
- When a new document is added to a section, link it from that section's
  index so nothing goes stale or undiscoverable.
